Projet_1_MakeCode - Détecteur d'obstacles
-----------------------------------------
Pour mon projet de prototypage, j'ai voulu créer un dispositif qui pourrait aider les personnes aveugles ou malvoyantes à détecter des obstacles pendant leurs déplacements. Mon idée était d'intégrer un senseur de mouvement au bord d'un bâton de mobilité, utilisé par ces personnes pour repérer les obstacles sur leur chemin. J'ai programmé le circuit avec MakeCode pour que, lorsque le bâton est secoué, un son se déclenche. J'ai aussi ajouté une animation lumineuse qui s'active pendant 500 millisecondes avant que les lumières s'éteignent. L'objectif est que quand le bâton cogne un obstacle, le mouvement déclenche le son et donne une information à la personne qui l'utilise. 

En réalisant ce projet, j'ai pu comprendre comment un senseur de mouvement peut détecter une secousse et déclencher un son et de la lumière. Cela m'a permis de mieux comprendre comment la programmation peut rendre un object interactif tout en gardant une fonction utile.

Projet_2_MadeCode - Indicateur de verdict
-----------------------------------------
Pour mon deuxième projet de prototypage, j'ai voulu créer un dispositif qui pourrait être utile lors de séances de débats entre des clubs de débats ou de questionnaires. L'idée serait de permettre au jury d'indiquer si une réponse est correcte ou incorrecte sans devoir toujours utiliser sa voix. J'ai programmé le circuit avec MakeCode pour que le bouton A permette de signaler une bonne réponse en déclenchant une lumière verte accompagnée d'une mélodie. Au contraire, le bouton B permet de signaler une mauvaise réponse en déclenchant une lumière rouge, également accompagnée d'une mélodie.

Pour réaliser ce projet, j'ai utilisé la fonction « if/else » afin de programmer les deux possibilités selon le bouton utilisé. Cette programmation m'a permis de comprendre comment les conditions peut déclencher différentes réponses.

Projet_3_Arduino - Poêle lumineuse
----------------------------------
Pour mon troisième projet de prototypage, j'ai voulu programmer mon Circuit Playground Express dans le but de créer un dispositif qui pourrait être utilisé dans des jeux de cuisine pour les enfants. Mon idée était de simuler le chauffage d'une poêle afin de rendre le jeu plus interactif. Lorsque la poêle est en mouvement, les lumières du circuit s'allument en orange pour représenter la chaleur produite pendant la cuissons des aliments. Quand la poêle devient immobile, les lumières s'éteignent pour indiquer qu'elle ne chauffe plus.

Pour réaliser ce projet, j'ai utilisé Arduino et programmé les axes en X et Y du senseur de mouvement pour détecter les mouvements du circuit. Selon les valeurs détectées, le code permet d'allumer les lumières orange ou de les éteindre. Ce projet m'a permis de mieux comprendre comment utiliser les axes X et Y pour détecter les mouvements et comment les intégrer dans le Circuit Playground Express.
